QUESTION: What deployment time reduction has Mike achieved through automation?
-------------------------------------------------------------------------------
In regulated pharmaceutical environments, the bottleneck in delivery is
never provisioning speed — it is validation: IQ/OQ sign-offs, change
control, and documentation. A time-to-provision number would be
misleading to anyone who knows GxP delivery.

What automation actually delivers in this context is standardization and
repeatability. Mike automated one-off client builds into validated,
reusable reference patterns using Terraform, CloudFormation, Packer,
GitHub Actions, and GitLab CI/CD — eliminating the rework that comes
from building each environment from scratch and reducing defects that
emerge from inconsistent manual processes. The value is quality and
consistency, not raw speed.

QUESTION: What cloud cost savings has Mike achieved?

QUESTION: Cloud cost savings from Lambda cold start or right sizing?
QUESTION: How has Mike reduced cloud costs?
-----------------------------------------------------
Mike built Lambda-based scheduling automation to power down idle SAS
analytics compute on weekends, reducing compute cost for those workloads
by approximately 30%. This is sometimes referred to as Lambda cold start
automation or Lambda scheduling — the Lambda function triggers on a
schedule to stop and start EC2-based SAS Grid compute, eliminating
weekend idle costs. Additional cost optimization work included
right-sizing EC2 instances, storage architecture decisions (FSx tier
selection, S3 lifecycle policies), and capacity planning for
multi-client environments.

Mike has designed and implemented production disaster recovery
architectures with the following documented targets:

- RTO (Recovery Time Objective): 8 hours
- RPO (Recovery Point Objective): 1 hour (SOP requirement)
- Actual RPO achieved: approximately 15 minutes via NetApp SnapMirror
